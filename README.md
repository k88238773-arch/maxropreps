# 🏈 MAXROPREPS — Roblox Football Recruiting Network

Welcome to **MAXROPREPS**, the premier dynamic database and community hub designed entirely for tracking, ranking, and recruiting Roblox football talent. 

This platform bridges the gap between rising athletes, competitive leagues, and verified team scouts by providing a centralized system to display player cards, update commitment sheets, and post game film.

## ⚡ Core Features

* **Custom Player Registration:** Athletes can create an official recruiting profile complete with multi-position select tags (Offense, Defense, and Special Teams), Roblox tags, and Discord handles.
* **The Explore Board:** A dedicated community feed where registered, logged-in players can submit their gameplay highlight URLs (YouTube, Streamable, Discord video links) with custom achievement titles.
* **Live Community Activity Trackers:** Any system update—whether an evaluator tweaks a player's star rating or an athlete drops a new highlight tape—instantly logs a notification to the live Activity feed.
* **Interactive Ranking Boards:** A national leaderboard that automatically sorts and displays registered athletes dynamically by their 1-5 star metrics.
* **Direct Messaging (DMs):** A secure, local messaging workspace allowing recruiters to reach out directly to athletes regarding league offers and tryouts.

## 🛠️ Technology Stack

* **Frontend:** Semantic HTML5 & Responsive CSS3 Grid layouts tailored for desktop and mobile displays.
* **Engine & Routing:** Vanilla JavaScript DOM manipulation and session state routers.
* **Database:** Client-side architecture powered by persistent `LocalStorage` browser tracking.
